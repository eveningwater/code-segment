standardDeviation 指标波动分析台

基于 standardDeviation 计算样本或总体标准差，结合均值与离群倍数（如 3σ）做 SRE / 质量监控里常见的「波动是否异常」判断；支持手动输入、示例数据与随机模拟，并可导出报告元数据。

1) 数据与数据源

可选；写入 CSV 首行注释。

2) 函数说明

第二个参数为 true 时使用总体标准差（除以 n）；默认样本标准差（除以 n−1）。样本量 n<2 时样本标准差无定义，页面会提示并跳过。
